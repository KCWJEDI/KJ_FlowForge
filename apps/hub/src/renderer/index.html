환경 설정

Settings API가 아직 연결되지 않았습니다. main 프로세스에서 getSettings / saveSettings / testIntegrations를 구현한 뒤 재시작하세요.

분야별 로컬 Git 저장소 폴더와 GitHub 저장소 URL을 설정하세요. 로컬 폴더는 커밋·푸시에 사용되고, URL은 원격 저장소를 식별하는 정보로 저장됩니다. Discord 알림 조건도 저장소별로 설정할 수 있습니다.

저장소별로 Notion 데이터베이스를 연결합니다. 저장소가 추가되면 여기에 자동으로 표시되며, 각 저장소에서 사용할 Notion Database ID를 지정할 수 있습니다. 표시 형식: 프로젝트이름 : 분야라벨 : 사용자이름

저장소별로 Discord 채널을 연결합니다. 저장소가 추가되면 여기에 자동으로 표시되며, 각 저장소에서 알림을 보낼 Discord 채널 ID를 지정할 수 있습니다. 표시 형식: 프로젝트이름 : 분야라벨 : 사용자이름

새 라이선스 키가 확인되면 프로그램이 자동으로 재시작되고 역할에 맞는 화면이 적용됩니다.
